One page displays a file as an endless stream of animated QR codes. Another device points its camera at the screen and reconstructs the file — no network path between the two devices, no pairing, no app permissions beyond the camera. Dropped frames cost a little time, never correctness: the stream is fountain-coded, so any frame the receiver catches, in any order, moves it closer to done.
